### Hi, I'm SubCoding 👋

Developer in Seoul. I build small macOS menu bar apps that each fix one annoying thing, and write about the tools I actually use.

맥에서 불편한 것 하나를 고치는 작은 앱을 만들고, 직접 써 본 개발 도구 이야기를 씁니다.

**Every app here:** free · open source · no network access · no analytics · menu bar only

---

#### 🍎 Mac apps

| App | What it does | |
|---|---|---|
| [**PortableHiDPI**](https://github.com/subbak2/PortableHiDPI) | Sharp HiDPI (Retina) text on 14–16" portable monitors, which macOS on Apple Silicon won't offer at comfortable sizes | [Download](https://github.com/subbak2/PortableHiDPI/releases/latest) · [한국어](https://github.com/subbak2/PortableHiDPI/blob/main/docs/manual-ko.md) |
| [**ScrollSplit**](https://github.com/subbak2/ScrollSplit) | Natural scrolling on the trackpad, regular scrolling on the mouse, at the same time | [Download](https://github.com/subbak2/ScrollSplit/releases/latest) · [한국어](https://github.com/subbak2/ScrollSplit/blob/main/docs/manual-ko.md) |

Both are a few hundred lines of Swift you can read in one sitting, with measured CPU/GPU numbers and a "what can go wrong" section in each README.
